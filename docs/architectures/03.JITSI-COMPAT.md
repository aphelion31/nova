# 03. Jitsi Meet compatibility

## Drop-in Embed & Config Surface

Existing applications integrating Jitsi Meet via iframe embed script continue working with zero client SDK rewrite:

- `GET /external_api.js` serves `JitsiMeetExternalAPI` (and `NovaMeetExternalAPI` alias) creating an iframe pointing at `/embed/{roomName}` with camera, microphone, display-capture, autoplay, clipboard-write, and fullscreen permissions.
- Supported `executeCommand` commands: `toggleAudio`, `toggleVideo`, `toggleShareScreen`, `toggleChat`, `toggleTileView`, `toggleRaiseHand`, `hangup`, `displayName`, `subject`, `password`, `sendChatMessage`, `muteEveryone`.
- Supported events via `addListener` / `on`: `videoConferenceJoined`, `videoConferenceLeft`, `participantJoined`, `participantLeft`, `audioMuteStatusChanged`, `videoMuteStatusChanged`, `incomingMessage`, `outgoingMessage`, `raiseHandUpdated`, `screenSharingStatusChanged`, `readyToClose`.
- Supported getters: `getParticipantsInfo()`, `getNumberOfParticipants()`, `isAudioMuted()`, `isVideoMuted()`, `dispose()`.
- `GET /config.js` and `GET /interface_config.js` serve dynamic runtime configuration scripts compatible with Jitsi embedders.

## JWT Room Tokens

Nova accepts and mints Jitsi-style HS256 JWTs (`POST /api/rooms/{name}/token` or `./nova token <room> --moderator`) using the claim layout:

```json
{
  "aud": "nova-meet",
  "iss": "nova-meet",
  "sub": "localhost",
  "room": "standup",
  "exp": 1795700000,
  "context": {
    "user": { "name": "Alice", "email": "alice@example.com", "moderator": true }
  }
}
```

Wildcard `"room": "*"` is honored when `aud` matches `JWT_APP_ID`.

## Ported vs Out of Scope

- **Ported:** Prejoin + live preview, multi-party SFU audio/video/screen-share, tile/speaker/spotlight layouts, active speaker detection + audio level rings, room lock/password, knock lobby, Argon2id host auth + JWT tokens, public chat + private DMs, emoji reactions, raise hand, polls, breakout rooms (SFU-isolated), collaborative whiteboard, speaker stats, E2EE key derivation + WebRTC Encoded Transform, client virtual blur, MediaRecorder recording, REST room API, EN/ID i18n, and native iOS/Android via UniFFI.
- **Intentionally omitted in v1.0.0:** Legacy Prosody XMPP/BOSH XML wire protocol, Jigasi SIP/PSTN dial-in, Jibri server-side Chrome recording/YouTube streaming, Dropbox/Salesforce/Amplitude SaaS integrations.
