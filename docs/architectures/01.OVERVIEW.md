# 01. Overview

## What Nova replaces

| Jitsi Meet Stack | Nova |
| --- | --- |
| Prosody (Lua XMPP + MUC + BOSH) | `crates/nova-server/src/ws.rs` + `rooms.rs` (WebSocket JSON signaling) |
| Jicofo (Java Conference Focus) | `crates/nova-server/src/rooms.rs` (lobby, lock, moderation, breakout, polls) |
| Jitsi Videobridge (Java SFU) | `crates/nova-server/src/sfu.rs` (`str0m 0.26` Sans-IO WebRTC SFU on multiplexed UDP) |
| Nginx static assets + `/external_api.js` | `crates/nova-server` (`tower-http` `ServeDir` + `compat.rs`) |
| React + Redux + Webpack web app | `web/` React Router 8 + React 19 + Tailwind CSS v4 + Vite 8 PWA (Bun `1.4.4`) |
| React Native iOS & Android + `lib-jitsi-meet` | `crates/nova-core` (UniFFI) + SwiftUI (`mobile/ios/`) & Kotlin Compose (`mobile/android/`) |

One binary serves the signaling WebSocket, HTTP API, drop-in Jitsi embed API, WebRTC SFU UDP media router, SQLite persistence, and static React Router PWA.

## Request & Media Flow

**Prejoin & Join.** The client opens `/room/{name}` (web) or parses the meeting URL via `NovaClientCore.parse_meeting_url` (mobile), previews local devices, and opens `/ws/{room}`. On `Join`, the server validates optional password or JWT room token (`HS256`), places newcomers in the lobby if enabled, and replies with `Joined { self_id, is_moderator, ice_servers, snapshot }`.

**SFU Negotiation.** After `Joined`, the client creates a local `RTCPeerConnection` with its microphone, camera, and optional screen-share tracks and sends `RtcOffer`. `sfu.rs` registers a `str0m::Rtc` instance on the room's multiplexed UDP socket, emits `RtcAnswer`, and whenever peers join or switch breakouts, pushes `RtcRenegotiateOffer { sdp, track_map }` so subscribers map each `mid` to its `owner_peer_id` and `kind`.

**Collaboration & Persistence.** Chat messages, direct messages, reactions, raised hands, polls, whiteboard strokes, breakout room moves, and speaker stats flow over `/ws/{room}`. Rooms, Argon2id host accounts, chat history, and polls persist in SQLite (`nova.db`).

## Limits

- **Single-node SFU.** In-process `str0m` SFU and room state live in one process; horizontal multi-region cascading requires an inter-bridge media relay.
- **Embedded SQLite default.** Zero external database dependency; write contention scales cleanly for single-node conferences under WAL mode.
