# 04. Deploy

## Build

```bash
# 1. Build React Router PWA into web/build/client
scripts/build-web.sh

# 2. Build single release binary
cargo build --release --locked
# -> target/release/nova
```

For Linux x86_64 glibc builds (e.g. Debian Bookworm / Ubuntu 24.04), build natively or inside Docker (`docker/axum/Dockerfile`). Ensure UDP port `10000/udp` (`SFU_UDP_BIND`) is reachable by WebRTC clients and set `SFU_PUBLIC_IP` to the server's public IPv4 address.

## Run

```bash
# Seed an optional host account
DATABASE_URL=sqlite://nova.db?mode=rwc ./target/release/nova seed host@example.com 'Strong-Pass-2026' 'Host'

# Serve HTTP + WebSocket (:3000) and SFU UDP (:10000)
BIND=0.0.0.0:3000 \
SFU_UDP_BIND=0.0.0.0:10000 \
SFU_PUBLIC_IP=203.0.113.10 \
SECRET_KEY_BASE=$(openssl rand -hex 64) \
JWT_APP_SECRET=$(openssl rand -hex 32) \
WEB_DIR=web/build/client \
./target/release/nova serve
```

Put a TLS reverse proxy (Caddy, Traefik, nginx) in front of `:3000` for HTTPS (browsers require a secure context for `getUserMedia` outside `localhost`), and forward WebSocket upgrades on `/ws/`. Keep `10000/udp` directly open on the host firewall (not proxied through nginx HTTP).

## Docker Compose

```bash
cp .env.example .env
# Edit SECRET_KEY_BASE, JWT_APP_SECRET, and SFU_PUBLIC_IP in .env
docker compose up -d --build
```

Note: `axum` publishes `10000:10000/udp` directly for WebRTC media while `nginx` fronts HTTP/WS on `:8080 -> :80`.
