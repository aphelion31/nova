# 02. Project structure

```text
nova/
├── Cargo.toml                        Rust workspace (nova-core + nova-server)
├── rustfmt.toml                      Formatting rules (max_width = 120)
├── crates/
│   ├── nova-core/                    Shared pure-Rust core + UniFFI 0.33 exports
│   │   ├── src/lib.rs                uniffi::setup_scaffolding!() + NovaClientCore
│   │   ├── src/protocol.rs           ClientMessage / ServerMessage WebSocket protocol
│   │   ├── src/state.rs              Deterministic RoomSnapshot state reducer
│   │   ├── src/e2ee.rs               HKDF + AES-256-GCM frame E2EE key helper
│   │   └── src/bin/uniffi-bindgen.rs Optional CLI binding generator (`--features bindgen`)
│   └── nova-server/                  Single-binary Rust backend (`nova`)
│       ├── migrations/0001_init.sql  SQLite schema (users, rooms, chat_messages, polls, sessions)
│       └── src/
│           ├── main.rs               CLI (`serve`, `seed`, `hash-password`, `token`), router, shutdown
│           ├── api.rs                REST API (/api/status, /api/config, /api/rooms/*)
│           ├── auth.rs               Argon2id host auth, signed cookie sessions, HS256 room JWT
│           ├── compat.rs             /config.js, /interface_config.js, /external_api.js
│           ├── db.rs                 SQLite pool + migrations + queries
│           ├── rooms.rs              Room registry, lock/lobby/moderation/polls/breakouts/whiteboard
│           ├── sfu.rs                str0m 0.26 Sans-IO WebRTC SFU + UDP multiplexer
│           ├── web.rs                Static SPA serving + health/ready probes
│           └── ws.rs                 /ws/{room} WebSocket signaling bridge
├── web/                              React Router 8 + Tailwind v4 PWA (Bun 1.4.4)
│   ├── app/routes.ts                 Route definitions
│   ├── app/routes/                   home, login, room, embed, not-found
│   ├── app/lib/                      api.ts, rtc.ts, blur.ts, e2ee.ts, external-bridge.ts, i18n.ts
│   ├── app/components/               PrejoinView, VideoStage, ControlDock, SidePanel, WhiteboardModal
│   └── public/                       brand-assets/*.svg, manifest.webmanifest, sw.js
├── mobile/                           Native SwiftUI + Kotlin Compose clients
│   ├── scripts/generate-bindings.sh  Generates Swift + Kotlin bindings from nova-core
│   ├── ios/                          SwiftPM package + SwiftUI app (`Generated/` + `Sources/NovaApp/`)
│   └── android/                      Gradle Jetpack Compose app (`app/src/main/`)
├── docker/                           Multi-stage Axum + Nginx configs
├── tools/                            smoke.sh, e2e.mjs, bench.sh
├── scripts/                          check-branch.sh, check-commit-msg.sh, new-branch.sh, build-web.sh
├── .githooks/                        commit-msg, pre-commit, pre-push
├── rust/                             whole-app port map, ADRs, glossary, research, handoff
└── docs/                             Architecture, compatibility, deployment, git docs, screenshots
```

## Environment

| Variable | Default | Purpose |
| --- | --- | --- |
| `BIND` | `0.0.0.0:3000` | HTTP + WebSocket listen address |
| `SFU_UDP_BIND` | `0.0.0.0:10000` | Multiplexed WebRTC media UDP port |
| `SFU_PUBLIC_IP` | auto-detected | Public/LAN IPv4 advertised in ICE host candidates |
| `DATABASE_URL` | `sqlite://nova.db?mode=rwc` | SQLite database file path |
| `WEB_DIR` | `web/build/client` | Built React Router SPA directory |
| `SECRET_KEY_BASE` | dev key | HMAC secret for `nova_session` cookies (set in production) |
| `JWT_APP_ID` | `nova-meet` | Expected JWT `aud` / `iss` claim |
| `JWT_APP_SECRET` | dev key | HS256 secret for Jitsi-compatible room JWTs |
| `FRONTEND_URL` | `http://localhost:3000` | Public base URL |
| `STUN_URL` | `stun:stun.l.google.com:19302` | Optional STUN URI exposed in ICE config |
| `RUST_LOG` | `info,str0m=warn,tower_http=warn` | Tracing filter |
