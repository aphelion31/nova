# Nova Docs

Reference documentation for the Nova codebase.

## Layout

- `docs/*.md` — architecture overview and shipped-artifact security audits (`ARCHITECTURE.md`, `REA-AUDIT.md`).
- `docs/architectures/` — layered system design, project layout, Jitsi compatibility mapping, and deployment guides.
- `docs/github/` — commit, branching (`NVA-NNN/*`), and PR workflow conventions.
- `docs/screenshots/` — 8 `2×` retina (`2880×1800`) screenshots captured from live 2-peer + Visitor Chromium + `str0m` SFU E2E runs (`tools/e2e.mjs`), including Visitor `JoinMeetingDialog`.
- `docs/media/` — animated walkthrough (`nova-demo.gif`, `nova-demo.mp4`) generated by `scripts/build-demo-media.sh`.
- `docs/images/` — auto-updated repository charts (`star-history.svg`).

## Conventions

- Keep root limited to `README.md`, `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `Cargo.toml`, `LICENSE*`, and build/compose manifests.
- Prefer updating existing docs over duplicating information.
- Refresh `docs/screenshots/*.png` and `docs/media/` whenever UI changes land in a release.
