# 02. Branch

Nova uses an integration branch (`develop`) and a release branch (`master`), and every work branch
carries an `NVA-<number>` ticket prefix.

| Branch | Purpose |
| --- | --- |
| `master` | Released code only. Moves when a release or hotfix is merged. Tagged `vX.Y.Z` |
| `develop` | Default and integration branch. All work branches start here and merge back |
| `NVA-NNN/<type>-<description>` | Feature, fix, refactor, docs or chore work, cut from `develop` |
| `release/<version>` | Release preparation, cut from `develop`, merged into `master` and `develop` |
| `hotfix/<version>` | Urgent production fix, cut from `master`, merged into `master` and `develop` |

Direct pushes to `develop` and `master` are blocked by `.githooks/pre-push`; work arrives by pull request.

## Work branch name

```text
NVA-<number>/<type>-<description>
```

- **`NVA-<number>`**: three or more digits, zero-padded: `NVA-001`, `NVA-042`, `NVA-1205`.
- **`<type>`**: `feat`, `fix`, `refactor`, `perf`, `docs`, `test`, `build`, `ci`, `chore`, `core`, `style`, `revert`.
- **`<description>`**: lowercase kebab-case.

## Create a work branch

```bash
scripts/new-branch.sh feat-sfu-simulcast
scripts/new-branch.sh NVA-020/fix-ice-restart
```
